# Project Guidelines & Rules

## Git Commit Rules

- **Commit Every Single File Edit**: Make a dedicated Git commit immediately after creating or modifying *every single individual file*.
- **Maximum Commit Frequency**: Commit as many times as possible for every minor tweak, code change, bug fix, feature addition, or refactor.
- **Micro & Atomic Commits**: Keep commits granular and focused on single-file modifications.
- **Clear Commit Messages**: Follow conventional commit conventions (e.g., `feat:`, `fix:`, `refactor:`, `docs:`, `chore:`).
- **Verify Before Committing**: Ensure changes are clean, functional, and properly staged before committing.
