# Project Guidelines & Rules

## Git Commit Rules

- **Commit Every File Edit**: Make a separate Git commit immediately after creating or editing every single file.
- **Frequent & Atomic Commits**: Make frequent git commits for every small change, feature addition, bug fix, or refactor.
- **Clear Commit Messages**: Follow conventional commit conventions (e.g., `feat:`, `fix:`, `refactor:`, `docs:`, `chore:`).
- **Verify Before Committing**: Ensure changes are clean, functional, and properly staged before committing.
